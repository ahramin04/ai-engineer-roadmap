# 🎤 AI Engineer Interview Map

## Core
- Python: OOP, data structures, async, typing, testing
- Backend: HTTP, REST, FastAPI, auth, caching, queues
- Data: SQL, indexing, transactions
- ML: metrics, leakage, overfitting, evaluation
- GenAI: tokens, embeddings, context, structured output
- RAG: chunking, retrieval, reranking, evaluation
- Agents: tools, state, planning, retries, guardrails
- Production: Docker, CI/CD, cloud, observability, security, cost

## Answer Pattern
**Problem → Architecture → Trade-off → Failure Mode → Mitigation → Metric**
