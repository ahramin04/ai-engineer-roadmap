## 🔁 Learning Loop

**Learn → Practice → Build → Test → Evaluate → Ship → Explain**

Don't count a topic as learned because you read about it. Build something, measure it, document it, and explain the trade-offs.

## 🗺️ Skill Map

**Software Engineering** → Python → Git → Linux → HTTP → APIs → SQL → Testing → Docker

**AI Application Engineering** → embeddings → semantic search → vector databases → RAG → reranking → structured outputs → tool calling

**Agent Engineering** → state → planning → tools → memory → orchestration → human approval → evaluation

**Production AI** → testing → security → observability → CI/CD → cloud → reliability → cost
